# Scott's Home Jobs PWA

A small offline-friendly Progressive Web App for tracking household responsibilities.

## Included defaults
- 8:00 pm — prepare breakfast for the next morning: porridge + Scott's beans
- 7:00 am — Alfie's apple juice
- 7:10 am — fill all water bottles
- Ongoing — check the water tank
- 8:10 pm — prepare kids' snacks
- Weekend — bake one large loaf/slice to last until Wednesday
- Ongoing — utility bills
- Ongoing — car service + registration

## Behaviour
- Daily tasks automatically get a fresh checkbox each calendar day.
- Weekly tasks reset each Monday.
- Ongoing tasks remain checked until you manually untick them.
- Everything is stored locally in the browser using localStorage.
- Use the settings button to edit, add, or remove responsibilities.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload every file/folder from this project to the repository root.
3. In GitHub: Settings → Pages.
4. Under "Build and deployment", choose "Deploy from a branch".
5. Choose `main` and `/ (root)`, then Save.
6. Open the Pages URL in Safari on iPhone.
7. Tap Share → Add to Home Screen.

No server or database is required.
